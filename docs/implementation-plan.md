# 制片工作台实施计划

目标：实现单制片维护的 React + FastAPI 工作台，支持 PostgreSQL，本地验证使用 SQLite。

设计依据：本次聊天确认的模块化单体、平行筹备、人工估时、Agent 工具、确认修改和通告版本方案。

1. 编写测试：项目隔离、旧版本保护、原子修改、确认幂等、通告快照、排期冲突、Agent 只生成草稿。
2. 实现数据库和业务服务：项目、场次、要求、筹备、排期、费用、事件和通告。
3. 实现 Agent：模型 API 接入、限定工具、项目上下文、持久化会话、修改草稿。
4. 实现 React 页面：项目切换、结构化录入、筹备筛选、排期、费用、通告、Agent 确认。
5. 运行后端测试和前端构建，记录启动方式、配置和实际限制。

暂不实现：多用户权限、离线同步、录音转写、OCR、自动分发、拖拽排期、向量检索。不得把这些能力显示为已完成。
